# 2026-05-15 15:25 — Auth Migration: Supabase → Prisma/SQLite Local Auth

## What was done
Replaced Supabase Auth with a local Prisma/SQLite-based auth system. No external service required.

### New files
- `src/lib/auth.ts` — Core auth utilities: `hashPassword`, `verifyPassword`, `createSession`, `deleteSession`, `getUser`
- `src/app/api/auth/login/route.ts` — POST: email/password login → sets session cookie
- `src/app/api/auth/signup/route.ts` — POST: create account → auto-login
- `src/app/api/auth/logout/route.ts` — POST: destroy session
- `src/app/api/auth/me/route.ts` — GET: return current user from session cookie

### Modified files
- `prisma/schema.prisma` — Added `Session` model with `@@map("sessions")`
- `src/lib/supabase/server.ts` — Rewritten: `createClient()` returns local auth wrapper
- `src/lib/supabase/client.ts` — Rewritten: client-side auth calls fetch to `/api/auth/*`
- `src/lib/supabase/middleware.ts` — Rewritten: reads session cookie, redirects unauthenticated
- `src/lib/supabase/env.ts` — Returns `null` (no external env needed)
- `src/lib/supabase/admin-client.ts` — Returns Prisma instance
- `src/stores/authStore.ts` — `LocalUser` type replaces Supabase `User`
- `src/hooks/useAuth.ts` — Calls fetch endpoints instead of Supabase SDK
- `src/app/api/auth/role/route.ts` — Uses `getUserId()` instead of Supabase
- `src/app/(auth)/onboarding/page.tsx` — Uses `getUser()` directly
- `src/app/(dashboard)/layout.tsx` — Uses `getUser()` directly
- `src/app/(dashboard)/dashboard/page.tsx` — null-safe email access
- `src/app/(teacher)/layout.tsx` — Uses `getUser()` directly
- `src/app/(teacher)/teacher/page.tsx` — null-safe email access
- `src/components/layout/header.tsx` — `avatarUrl` replaces `user_metadata.avatar_url`
- `src/lib/env.ts` — Removed Supabase env vars
- `.env.local` / `.env.local.example` — Removed `NEXT_PUBLIC_SUPABASE_*`, kept `DATABASE_URL`
- `.env` — Created for Prisma CLI compatibility

### Removed
- `src/app/(auth)/callback/route.ts` — OAuth callback no longer needed
- `web/supabase/` — Migrations directory removed
- `@supabase/supabase-js`, `@supabase/ssr` packages removed
- `SUPABASE_SERVICE_ROLE_KEY` from env
