## Blockers / Notes
- Prisma 7 requires a driver adapter (SQLite → @prisma/adapter-libsql + @libsql/client)
- Auth (login/signup) still requires Supabase — works when env vars are configured
- Without Supabase, the app loads but protected routes redirect to /login and auth features show "not configured" errors
- The generated Prisma client is at src/generated/prisma/ (custom output path)
- SST persistence errors in .next-dev.err.log are Turbopack internals, not application errors
