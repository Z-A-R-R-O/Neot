## What was done

### Password Reset (Z-01: Auth)
- `prisma/schema.prisma` — added `PasswordResetToken` model with token, expiry, used flag, cascade delete
- `src/app/api/auth/forgot-password/route.ts` — new POST endpoint: generates random token, stores with 1h expiry, invalidates old tokens, returns reset URL (email integration scaffolded)

### Notification System Expansion (Z-01: Notifications)
- `src/lib/notifications.ts` — expanded with:
  - `NOTIFICATION_TYPES` constant with 11 typed notification types (info, xp_gained, achievement_unlocked, level_up, quiz_result, streak_milestone, course_published, course_completed, message, grading_alert, streak_reminder)

  - `sendStreakReminder()` — nudge when streak at risk

- `src/app/api/notifications/unread-count/route.ts` — new lightweight GET endpoint for header badge polling (returns just count, not full list)
- `src/components/notifications/notification-bell.tsx` — updated typeColors and typeIcons maps for all 11 new notification types
