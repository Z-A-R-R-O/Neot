# Session: V3-1 — Learning Worlds UI (initial build)

## What changed

### API Routes
- `GET /api/worlds` — list worlds with progress for current student
- `GET /api/worlds/[id]` — world detail with islands and progress
- `GET /api/worlds/[id]/islands` — islands with concept/prerequisite data
- `GET /api/worlds/[id]/skill-tree` — concept graph (nodes + edges)
- `POST /api/worlds/progress` — update island/world completion status

### Components
- `WorldCard` — themed card with progress bar, island count, locked/status badges
- `WorldsContent` — worlds list page with loading/error/empty states and stagger animation
- `WorldDetailContent` — world detail with progress bar + island cards
- `IslandCard` — island card with status icon, concept count, progress bar
- `IslandDetailContent` — island detail with concept list, locked state
- `WorldProgressBar` — visual node-based progress through island chain
- `SkillTree` — SVG-based concept graph layout with connection lines
- `SkillTreeNode` — individual concept node with mastered/in-progress/locked states

### Pages
- `/worlds` — Learning Worlds landing page (static metadata)
- `/worlds/[worldId]` — World detail page (dynamic metadata from Prisma)
- `/worlds/[worldId]/islands/[islandId]` — Island detail page

### Navigation
- Added "Learning Worlds" as primary student nav item (Earth icon)
- Added `Earth` icon to sidebar icon map

## Why
- V3-1 delivers the core Learning Worlds experience: world browsing, island progress, skill tree visualization
- Navigation puts Learning Worlds front and center for students
