# 2026-05-17 — Notification System Expansion

## What was done

### 1. Notification Bell UI (notification-bell.tsx)
- Added `level_up`, `quiz_result`, `streak_milestone`, `course_publish` types to `typeColors` with distinct color schemes
- Added `typeIcons` map for emoji icons per type
- Made notification items **clickable** — clicking a notification marks it as read and navigates to its `link` via `router.push()`
- Mark-as-read X button uses `e.stopPropagation()` to prevent click-through

### 2. Quiz Score Notifications (quizzes/[blockId]/attempt/route.ts)
- After quiz attempt, creates a notification with `type: "quiz_result"`
- Shows score fraction + percentage
- Includes XP awarded on pass
- Links back to lesson

### 3. Streak Milestone Notifications (lessons/[id]/progress/route.ts)
- In `awardLessonXp()`, after streak calculation, checks if new streak hits a milestone
- Milestones: 3, 7, 14, 30, 50, 100 days
- Creates notification with `type: "streak_milestone"` and fire emoji

### 4. Course Publish Notifications (courses/[id]/route.ts)
- In PATCH handler, detects transition from draft → published
- Finds all enrolled students via Enrollment model
- Uses `createMany` to batch-create notifications
- Links to course page

## Notification types now active
| Type | Trigger | Link |
|---|---|---|
| `achievement` | Achievement unlocked | /dashboard/achievements |
| `course_complete` | Course finished | /courses/:id/certificate |
| `level_up` | Level increased | /dashboard |
| `quiz_result` | Quiz attempted (pass/fail) | /lessons/:id |
| `streak_milestone` | 3/7/14/30/50/100 day streak | /dashboard |
| `course_publish` | Course published (to enrolled) | /courses/:id |
