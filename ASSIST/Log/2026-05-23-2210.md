# Session: V3-2 — AI Personalization Engine (foundation)

## What changed

### API Routes (7 new)
- `GET /api/student/learning-profile` — retrieve learning style + preferences
- `PUT /api/student/learning-profile` — update preferences, override style
- `POST /api/student/detect-style` — passive analysis from lesson metadata
- `GET /api/path/current` — next island/world in student's journey
- `GET /api/path/recommendations` — personalized next-step recs based on style
- `POST /api/path/generate` — generates full path with content type preferences per style
- `GET /api/student/weakness-report` — weak areas based on progress + gaps
- `POST /api/lesson/difficulty-feedback` — log difficulty rating per lesson

### Provider
- `LearningStyleProvider` — React context wrapping QueryProvider, exposes `profile`, `loading`, `detectStyle()`, `updateProfile()`, `refresh()`
- Wired into `web/src/app/providers.tsx`

### Components
- `StyleQuiz` — 5-question interactive quiz with animations, score breakdown
- `LearningProfileContent` — full profile page: display style, detect, take quiz, preferences
- `NextUp` — dashboard widget showing current island/world with continue link
- `WeakAreaPanel` — weakness report with stat cards + progress bars per weak area

### Pages
- `/student/learning-profile` — Learning Profile page
