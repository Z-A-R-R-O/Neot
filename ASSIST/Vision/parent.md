# Parent Dashboard — Spec

## Overview

Parents monitor their children's learning progress, communicate with teachers, and support home learning.

## Core Features

### Dashboard

- Child overview (multiple children supported)
- Current progress per child
- Recent activity feed
- Upcoming assignments and deadlines
- Achievement notifications

### Progress Monitoring

- Per-child course progress
- Quiz scores and trends
- Time spent learning (daily/weekly)
- Streak and engagement metrics
- Skill mastery breakdown
- Comparison to class average (optional)

### Communication

- Messages from teachers
- School announcements
- Parent-teacher meeting scheduler
- Feedback on child's progress
- Support ticket system

### Home Learning Support

- Suggested activities based on weak areas
- Printable worksheets
- Learning tips per subject
- Screen time management tools
- Reward system integration

### Settings

- Notification preferences
- Child account linking
- Privacy controls
- Language preferences

## User Flow

```
Login → Dashboard → Select Child → View Progress → Communicate → Support Learning
```

## Key Metrics Displayed

| Metric | Description |
|--------|-------------|
| Progress % | Overall course completion |
| Quiz Average | Mean score across all quizzes |
| Streak | Consecutive days of activity |
| Time Spent | Hours this week |
| Weak Areas | Topics needing review |
| Next Deadline | Upcoming assignment due date |
