# NEOT — Vision

## Mission

Build the free AI-powered learning universe that adapts to every student.

## Core Philosophy

> **"Every student learns differently. NEOT adapts to the student."**

This is our moat. Not courses, not ads, not certificates. The ability to personalize learning at scale.

- **Adaptive by design** — Dynamic learning paths adjust to each student's pace, style, and mastery
- **AI-personalized** — AI restructures knowledge per student, generating stories, simplified explanations, and targeted practice
- **Free + accessible** — Education should be free. Non-intrusive ads fund the platform, not paywalls
- **Gamified naturally** — Learning Worlds, quests, XP, streaks, badges — curiosity-driven engagement
- **Curiosity-first** — The system recommends exciting topics, not just the next lesson in a linear sequence
- **Learning Graph architecture** — Skill → Concept → Dependency → Mastery replaces rigid Course → Lesson structures
- **Tutor + AI hybrid** — Human tutors provide knowledge; AI personalizes it for every student

## Target Users

| Role | Primary Need |
|------|-------------|
| **Student** | Personalized, engaging, free learning adapted to how they learn |
| **Tutor** | Contribute knowledge, reach students globally, earn through content |
| **Parent** | Support child's self-directed learning, monitor progress |
| **Admin** | Manage platform, analytics, content, sponsorships |

## Key Differentiators

1. **Dynamic Learning Paths** — Every student gets a unique path based on their learning style, mastery, and curiosity
2. **Learning Graph** — Concept dependency chains that automatically detect and rebuild weak foundations
3. **AI Story Generator** — Explains concepts through narratives, not just dry text
4. **Learning Style Detection** — Passive analysis adapts content format (visual/audio/reading/kinesthetic)
5. **Curiosity Engine** — Recommends exciting related topics beyond the current path
6. **Memory Optimizer** — Personalized spaced repetition with optimal review timing
7. **Learning Worlds** — Gamified geographic metaphor (islands, dungeons, kingdoms) replaces course catalogs
8. **Free + Non-Intrusive Ads** — No paywalls, no popups, no mid-video ads. Passive educational ads fund free access.

## Business Model

| Tier | Price | Features |
|------|-------|----------|
| **Free** | $0 | Full access to all learning worlds. Supported by non-intrusive ads. |
| **Premium** | Optional | Ad-free experience, priority AI features, offline downloads |

## Success Metrics

- Student engagement (DAU, session length, quest completion rate)
- Learning outcomes (mastery scores, retention curves, time-to-mastery)
- Learning style detection accuracy and adaptation satisfaction
- Platform performance (page load < 1.5s, AI feature latency < 2s)
- Ad revenue sustainability (RPM, fill rate, user satisfaction)
- Content breadth (worlds, concepts, stories generated)
