# NEOT — Vision

## Mission

Build a lightweight, adaptive learning platform that makes education engaging, personalized, and accessible for students, teachers, parents, and schools.

## Core Philosophy

- **Lightweight first** — Fast load times, minimal dependencies, no bloat
- **Adaptive by design** — Content adjusts to each student's pace and level
- **Gamified naturally** — XP, streaks, badges, levels — motivation built in
- **AI-assisted, not AI-dependent** — AI enhances but doesn't replace core experience
- **Mobile-native** — Flutter app for iOS/Android, not a web wrapper
- **Modular architecture** — Features can be enabled/disabled per tenant

## Target Users

| Role | Primary Need |
|------|-------------|
| **Student** | Learn at their own pace with engaging, adaptive content |
| **Teacher** | Create courses, assign work, track progress easily |
| **Parent** | Monitor child's learning, communicate with teachers |
| **Admin** | Manage platform, analytics, billing, content library |
| **School** | White-label deployment, bulk management, reporting |

## Key Differentiators

1. **Visual Experience Engine (Dev Mode)** — Real-time UI customization without code
2. **Adaptive Learning Engine** — Difficulty adjusts based on performance
3. **Section Registry** — Extensible content blocks (video, quiz, interactive, etc.)
4. **Theme Engine** — Multi-mode operation with custom themes per tenant
5. **Lightweight Stack** — Next.js 16, Prisma/SQLite, minimal dependencies

## Business Model

| Tier | Price | Features |
|------|-------|----------|
| **Free** | $0 | Basic courses, limited storage |
| **Pro** | $9.99/mo | Full features, analytics, AI tutor |
| **School** | Custom | White-label, bulk licenses, admin tools |
| **Enterprise** | Custom | API access, SLA, dedicated support |

## Success Metrics

- Student engagement (daily active users, session length)
- Learning outcomes (quiz scores, completion rates)
- Teacher adoption (courses created, assignments given)
- Platform performance (page load < 2s, uptime > 99.9%)
